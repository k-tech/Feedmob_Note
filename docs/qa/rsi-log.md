## 2026-10-23 — Markdown 输入

- **起点**：上一轮 PR #2 已合并，切换 main 并拉取到 `8fc43f5`，工作区干净，没有未合并 PR。从最新 main 新建 `rsi/2026-10-23-markdown-input`，按上一轮「下次优先」测试 Markdown 输入；上轮多段列表 Shift+Tab 的产品问题仍待确认，不改其行为。
- **范围**：`#`、`-`、`1.`、`[]`、`>`、代码围栏、`---`、行内粗体/斜体/代码/删除线/高亮/链接；中文输入法的 `＃`、`》`、`【】`、`···`、`1。`、`、`，以及列表项内转换、退格撤销输入规则和 Cmd+Z/重做。
- **发现与修复（4 项）**：
  1. 列表项开头输入 `5. ` 等非 1 起号的标记，实际转换后从 1 编号。预期使用输入的起点。为共享 `applyBlockConversion` 添加可选目标属性，将起号从输入规则传到有序列表；相邻同类列表仍按既定规则合并连续编号。
  2. 列表项开头输入带语言的代码围栏（如三个反引号加 `ts` 和空格），实际不转换，普通段落中同样输入则可转换。统一两条路径的围栏正则，支持语言并经共享转换函数保留语言属性；转换仍保留前后列表及自身起号。
  3. 在列表项 `乙` 前输入 `## ` 后立即退格，再输入 `X`，实际还原了 `## 乙`，但把 `X` 写到下一项 `丙` 的末尾。根因是整个列表替换的逆映射把光标映射到后段。`BlockKeymap` 退格撤销输入规则时，在同一事务按原输入位置恢复光标，后续文字写回标记后。
  4. 开启粗体后输入 Markdown 链接，实际转换清掉粗体；混合格式标签也会丢格式。链接规则改为保留已有标签的富文本片段，对一次提交的新标签文字保留输入格式，再添加链接标记。兼容选区替换、部分标签一次提交和中文全角写法。
- **失败测试先行**：`tests/rsi-markdown-input.test.tsx` 最初 7 项在修复前失败；追加的独立退格光标测试也先失败并在真实浏览器复现。最终共新增 10 项，覆盖三类列表、三种围栏语言写法、多种数字标点、输入规则退格、链接混合格式/一次输入/选区替换/部分提交及链接后继续输入。
- **浏览器**：复用 `.runtime/rsi/` 隔离页面，重新 esbuild 打包真实 `BlockEditor.tsx` 和 Tailwind 样式。Playwright + Chromium 45 个断言场景通过；中文输入法使用 CDP `Input.imeSetComposition` + `Input.insertText`，检查组词期间不转换、提交后转换。默认 60ms 按键间隔，三个代表问题另以 250ms 复核；覆盖 Cmd+Z/重做、输入法 `、` 打开菜单、拒绝危险链接和代码中保留字面 Markdown，无页面错误。脚本为 `markdown-verify.mjs`，失败/慢速复现、验证日志与截图保留在忽略目录。

- **发现与修复（3 项）**：
